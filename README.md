# Healthy Posture Reminder Dashboard

Dashboard Streamlit untuk checklist Data Science Capstone.

## File yang harus ada dalam satu folder

- app.py
- requirements.txt
- healthy_posture_modeling.csv
- healthy_posture_model.keras
- label_encoders.pkl
- label_encoder_target.pkl
- scaler.pkl

## Cara menjalankan di lokal

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Cara deploy

Upload semua file ke GitHub, lalu deploy repository tersebut melalui Streamlit Cloud.
